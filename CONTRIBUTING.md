# Contributing / 参与贡献

[Home](README.md) · [中文首页](docs/readme/README.zh-CN.md)

Improvements to translations, setup guides, examples and tool descriptions are welcome. Open an issue describing the change, or submit a focused pull request with the reason and validation results. Keep all README language versions aligned when changing public claims or release status.

欢迎改进翻译、接入说明、示例与工具介绍。可在 Issue 描述建议，或提交范围清晰的 Pull Request，说明修改原因及验证结果。更新公开能力或发布状态时，同步所有语言版本的 README。

Use synthetic examples. Omit tokens, customer information, internal API drafts and private business implementation. For account or service access issues, contact your Biointron representative.

示例应使用虚构数据，不包含令牌、客户资料、内部 API 草案或业务实现。账号及服务权限问题请联系百英对接人。

Contributions are subject to the repository's [license](LICENSE); retain any applicable third-party notices.

贡献内容适用仓库的[许可证](LICENSE)，并须保留适用的第三方声明。
