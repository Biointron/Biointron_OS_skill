## Одна платформа. Три способа подключения.

Biointron OS — интерфейс к сервисам Biointron для ИИ-агентов, моделей и людей. Он объединяет доступ к сервисам и инструкции по рабочим процессам. План развития охватывает заказы, передачу проектных данных, отслеживание хода работ и получение результатов.

| Для агентов | Для моделей | Для людей |
| :--- | :--- | :--- |
| Находите и вызывайте сервисы через **MCP**. | Работайте со **структурированными данными** и документированными интерфейсами. | Используйте рабочие процессы через **интерактивный интерфейс**. |
| Дополняйте вызовы инструментов Skills для конкретных задач. | Соглашения о данных согласуются в ходе Beta. | Веб-интерфейс предоставляется отдельно от этого репозитория. |

Этот репозиторий — общедоступное место размещения Skills, руководств по подключению, каталога инструментов и примеров. Бизнес-сервисы Biointron работают отдельно.

## Начало работы

### 1 · Подключите MCP

Получите токен доступа к сервису и разрешение на его использование у своего представителя Biointron. В MCP-клиенте с поддержкой **Streamable HTTP** и **аутентификации Bearer** добавьте:

| Параметр | Значение |
| :--- | :--- |
| Имя | `BiointronOS_MCP` |
| Транспорт | Streamable HTTP |
| URL | `https://mcp-rusta-order-blgdfvompw.cn-shanghai.fcapp.run/mcp` |
| Аутентификация | `Authorization: Bearer <MCP_ACCESS_TOKEN>` |

В клиентах, поддерживающих формат `mcpServers`, можно объединить следующую конфигурацию с существующими настройками, заменив заполнитель токена своим токеном.

```json
{
  "mcpServers": {
    "BiointronOS_MCP": {
      "url": "https://mcp-rusta-order-blgdfvompw.cn-shanghai.fcapp.run/mcp",
      "headers": {
        "Authorization": "Bearer <MCP_ACCESS_TOKEN>",
        "START_MCP_TIMEOUT_MS": "60000",
        "RUN_MCP_TIMEOUT_MS": "660000"
      }
    }
  }
}
```

Два заголовка тайм-аута — пользовательские параметры приведённой конфигурации: 60000 миллисекунд равны 60 секундам, а 660000 миллисекунд — 11 минутам. Они действуют только при поддержке со стороны клиента или сервиса. Само по себе добавление этих полей в `headers` не гарантирует изменения времени ожидания клиента; конкретные настройки задавайте согласно документации клиента.

Подробнее о настройке см. в [руководстве по установке](../../docs/installation.md#mcp).

### 2 · Добавьте Skills

Выберите выпущенный Skill в [каталоге Skills](../../skills/README.md). Скачайте всю папку, включая `references/`, поставляемые скрипты и другие файлы, на которые ссылается Skill, и поместите её в каталог Skills вашего агента. Для Codex и Claude Code см. [установку Skills](../../docs/installation.md#skills).

Оба пакета Skills включены в этот репозиторий и доступны для скачивания. `auto_html_report` работает с существующим JSON результатов, предоставленным пользователем. Получение данных из сервиса не входит в его задачи: одного номера заказа для создания отчёта недостаточно.

### 3 · Начните с ознакомления в режиме чтения

```text
Перечисли инструменты Biointron MCP, доступные в этом сеансе, и объясни назначение каждого.
Расскажи, какие возможности готовы к работе, а какие ещё находятся на стадии Beta.
Не создавай и не отправляй заказы.
```

Обнаружение инструментов — первая проверка подключения. Для успешного выполнения бизнес-операции необходимо отдельно проверить подключение к соответствующему серверному сервису.

## Каталог инструментов MCP

| Инструмент | Назначение | Действие |
| :--- | :--- | :--- |
| `order_design_preflight` | Проверяет право компании на обслуживание и доступные исследования. | Только чтение |
| `start_order_design` | Передаёт предоставленный XLSX и ожидает подтверждения сохранения проекта. | Запись бизнес-данных |
| `add_order_to_cart` | Добавляет в корзину проект с подтверждённым сохранением. | Запись бизнес-данных |
| `get_order_cart` | Читает корзину заказов. | Только чтение |
| `calculate_order_price` | Получает расчёт стоимости выбранных заказов. | Только чтение |
| `submit_verified_order` | Проверяет стоимость и отправляет выбранные заказы. | Запись бизнес-данных |
| `get_report_results` | Получает существующие результаты отчёта в формате JSON. | Только чтение |

Эти семь инструментов зарегистрированы в текущей реализации MCP. Готовность всего бизнес-процесса к сквозной работе ещё предстоит проверить. См. [сигнатуры, состояние и ограничения](../../docs/tool-catalog.md).

## Skills

| Skill | Назначение | Состояние выпуска |
| :--- | :--- | :--- |
| [Подготовка заказа · `order-design`](../../skills/order_design/SKILL.md) | Задаёт порядок обработки заявок, передачи проектных данных и отправки заказов. | Включён · Доступен для скачивания |
| [Отчёт по результатам · `auto_html_report`](../../skills/auto_html_report/SKILL.md) | Создаёт автономные многоязычные HTML-отчёты из предоставленного пользователем JSON существующих результатов, включая сводную таблицу, графики и доступные изображения. | Включён · Доступен для скачивания |

MCP предоставляет операции, а Skills описывают, как агент использует их в рамках задачи. Установка Skill не даёт доступа к сервису и не регистрирует MCP автоматически. [Открыть каталог →](../../skills/README.md)

<a id="beta"></a>

## Beta Playground

Biointron OS внедряется в формате Beta Playground. Некоторые подключения пока могут быть недоступны. Сообщайте фактический результат каждого шага: успешный HTTP-ответ или наличие имени инструмента не подтверждают завершение бизнес-операции.

Для создания и отправки заказов требуется разрешение пользователя. Если время ожидания операции записи истекло, перед повторной попыткой проверьте состояние существующего заказа. По вопросам доступа или недоступных возможностей обращайтесь к представителю Biointron, предоставившему вам учётную запись.

## Вопросы и ответы

<details>
<summary><strong>Нужны ли мне одновременно MCP и Skills?</strong></summary>

MCP предоставляет вызываемые инструменты. Skills добавляют инструкции по рабочим процессам и могут иметь собственные зависимости. Следуйте требованиям каждого выпущенного Skill: одно лишь скачивание Skill не подключает сервис.

</details>

<details>
<summary><strong>Означает ли наличие инструмента в списке, что он готов к работе с бизнес-задачами?</strong></summary>

Нет. Обнаружение подтверждает только регистрацию инструмента. Также необходимо проверить настройки серверной части, права доступа учётной записи и запрошенную операцию. В каталоге эти состояния различаются.

</details>

<details>
<summary><strong>Где находятся сервер и реализация бизнес-логики?</strong></summary>

В этом репозитории распространяются общедоступные материалы для интеграции и Skills. Размещённый сервис и закрытая реализация бизнес-логики поддерживаются отдельно.

</details>
