## หนึ่งแพลตฟอร์ม สามรูปแบบการเชื่อมต่อ

Biointron OS คืออินเทอร์เฟซสำหรับเข้าถึงบริการ Biointron ที่ออกแบบมาสำหรับ AI Agent โมเดล และผู้ใช้ โดยรวมการเข้าถึงบริการกับคำแนะนำขั้นตอนการทำงานไว้ด้วยกัน พร้อมแผนการพัฒนาที่ครอบคลุมคำสั่งซื้อ การส่งข้อมูลการออกแบบ ความคืบหน้า และผลลัพธ์

| สำหรับเอเจนต์ | สำหรับโมเดล | สำหรับผู้ใช้ |
| :--- | :--- | :--- |
| ค้นหาและเรียกใช้บริการผ่าน **MCP** | ทำงานกับ**ข้อมูลที่มีโครงสร้าง**และอินเทอร์เฟซที่มีเอกสารกำกับ | เข้าถึงขั้นตอนการทำงานผ่าน**อินเทอร์เฟซแบบโต้ตอบ** |
| ใช้การเรียกเครื่องมือร่วมกับ Skills ที่เหมาะกับแต่ละงาน | อยู่ระหว่างปรับข้อตกลงด้านข้อมูลให้สอดคล้องกันในช่วง Beta | บริการผ่านเว็บให้บริการแยกจากคลังโค้ดนี้ |

คลังโค้ดนี้เป็นแหล่งเผยแพร่ Skills คู่มือการเชื่อมต่อ รายการเครื่องมือ และตัวอย่างสำหรับสาธารณะ ส่วนบริการทางธุรกิจของ Biointron ทำงานแยกต่างหาก

## เริ่มต้นใช้งาน

### 1 · เชื่อมต่อ MCP

ขอโทเค็นสำหรับเข้าถึงบริการและสิทธิ์การใช้งานจากผู้ประสานงาน Biointron ของคุณ จากนั้นเพิ่มข้อมูลต่อไปนี้ในไคลเอนต์ MCP ที่รองรับ **Streamable HTTP** และ**การยืนยันตัวตนแบบ Bearer**:

| การตั้งค่า | ค่า |
| :--- | :--- |
| ชื่อ | `BiointronOS_MCP` |
| รูปแบบการรับส่ง | Streamable HTTP |
| URL | `https://mcp-rusta-order-blgdfvompw.cn-shanghai.fcapp.run/mcp` |
| การยืนยันตัวตน | `Authorization: Bearer <MCP_ACCESS_TOKEN>` |

สำหรับไคลเอนต์ที่รองรับรูปแบบ `mcpServers` คุณสามารถรวมการกำหนดค่าด้านล่างเข้ากับการตั้งค่าที่มีอยู่ แล้วแทนที่ข้อความตัวแทนโทเค็นด้วยโทเค็นของคุณเอง

```json
{
  "mcpServers": {
    "BiointronOS_MCP": {
      "url": "https://mcp-rusta-order-blgdfvompw.cn-shanghai.fcapp.run/mcp",
      "headers": {
        "Authorization": "Bearer <MCP_ACCESS_TOKEN>",
        "START_MCP_TIMEOUT_MS": "60000",
        "RUN_MCP_TIMEOUT_MS": "660000"
      }
    }
  }
}
```

ส่วนหัวการหมดเวลาทั้งสองเป็นรายการที่กำหนดเองในตัวอย่างการตั้งค่า: 60000 มิลลิวินาทีเท่ากับ 60 วินาที และ 660000 มิลลิวินาทีเท่ากับ 11 นาที ส่วนหัวเหล่านี้จะมีผลตามที่กำหนดก็ต่อเมื่อไคลเอนต์หรือบริการรองรับเท่านั้น การใส่ไว้ใน `headers` เพียงอย่างเดียวไม่ได้รับประกันว่าจะเปลี่ยนระยะเวลารอของไคลเอนต์ โปรดตั้งค่าตามเอกสารของไคลเอนต์ที่ใช้

ดูรายละเอียดเพิ่มเติมได้ใน[คู่มือการติดตั้ง](../../docs/installation.md#mcp)

### 2 · เพิ่ม Skills

เลือก Skill ที่เผยแพร่แล้วจาก[รายการ Skills](../../skills/README.md) ดาวน์โหลดโฟลเดอร์ทั้งหมดรวมถึง `references/` สคริปต์ที่แนบมา และไฟล์อ้างอิงอื่น ๆ แล้วนำไปไว้ในไดเรกทอรี Skill ของเอเจนต์ ดูวิธีสำหรับ Codex และ Claude Code ได้ที่[การติดตั้ง Skill](../../docs/installation.md#skills)

แพ็กเกจ Skill ทั้งสองรวมอยู่ในคลังนี้แล้วและสามารถดาวน์โหลดได้ `auto_html_report` ใช้ JSON ของผลลัพธ์ที่มีอยู่ซึ่งผู้ใช้ส่งมาเป็นข้อมูลเข้า Skill นี้ไม่ได้ดึงข้อมูลจากบริการ การมีเพียงหมายเลขคำสั่งซื้อจึงไม่เพียงพอสำหรับสร้างรายงาน

### 3 · เริ่มทดลองแบบอ่านอย่างเดียว

```text
แสดงรายการเครื่องมือ Biointron MCP ที่ใช้ได้ในเซสชันนี้ และอธิบายหน้าที่ของแต่ละเครื่องมือ
บอกว่าความสามารถใดพร้อมใช้งานแล้ว และความสามารถใดยังอยู่ในช่วง Beta
อย่าสร้างหรือส่งคำสั่งซื้อ
```

การค้นพบเครื่องมือเป็นขั้นตอนแรกในการตรวจสอบการเชื่อมต่อ การดำเนินงานทางธุรกิจให้สำเร็จยังต้องตรวจสอบการเชื่อมต่อกับระบบเบื้องหลังที่เกี่ยวข้องด้วย

## รายการเครื่องมือ MCP

| เครื่องมือ | วัตถุประสงค์ | ผลของการทำงาน |
| :--- | :--- | :--- |
| `order_design_preflight` | ตรวจสอบสิทธิ์ของบริษัทและรายการทดสอบที่มีให้บริการ | อ่านอย่างเดียว |
| `start_order_design` | ส่งไฟล์ XLSX ที่ได้รับและรอการยืนยันว่าบันทึกแบบแล้ว | เขียนข้อมูลทางธุรกิจ |
| `add_order_to_cart` | เพิ่มแบบที่ยืนยันการบันทึกแล้วลงในตะกร้า | เขียนข้อมูลทางธุรกิจ |
| `get_order_cart` | อ่านตะกร้าคำสั่งซื้อ | อ่านอย่างเดียว |
| `calculate_order_price` | ขอใบเสนอราคาสำหรับคำสั่งซื้อที่เลือก | อ่านอย่างเดียว |
| `submit_verified_order` | ตรวจสอบราคาและส่งคำสั่งซื้อที่เลือก | เขียนข้อมูลทางธุรกิจ |
| `get_report_results` | ดึงผลรายงานที่มีอยู่ในรูปแบบ JSON | อ่านอย่างเดียว |

เครื่องมือทั้งเจ็ดรายการนี้ลงทะเบียนไว้ในระบบ MCP ปัจจุบันแล้ว แต่ยังต้องตรวจสอบความพร้อมของกระบวนการทางธุรกิจตั้งแต่ต้นจนจบ ดู[รูปแบบพารามิเตอร์ สถานะ และข้อจำกัด](../../docs/tool-catalog.md)

## Skills

| Skill | วัตถุประสงค์ | สถานะการเผยแพร่ |
| :--- | :--- | :--- |
| [การออกแบบคำสั่งซื้อ · `order-design`](../../skills/order_design/SKILL.md) | แนะนำขั้นตอนคำขอสั่งซื้อ การส่งข้อมูลการออกแบบ และการส่งคำสั่งซื้อ | รวมอยู่แล้ว · ดาวน์โหลดได้ |
| [รายงานผลลัพธ์ · `auto_html_report`](../../skills/auto_html_report/SKILL.md) | สร้างรายงาน HTML แบบแยกไฟล์ที่ใช้งานได้ด้วยตัวเองในหลายภาษา จาก JSON ของผลลัพธ์ที่มีอยู่ซึ่งผู้ใช้ส่งมา พร้อมตารางสรุป แผนภูมิ และรูปภาพที่มีให้ | รวมอยู่แล้ว · ดาวน์โหลดได้ |

## Beta Playground

Biointron OS กำลังเปิดตัวในรูปแบบ Beta Playground การเชื่อมต่อบางส่วนอาจยังใช้งานไม่ได้ โปรดรายงานผลจริงของแต่ละขั้นตอน การได้รับผล HTTP ที่สำเร็จหรือมองเห็นชื่อเครื่องมือไม่ได้ยืนยันว่าการดำเนินงานทางธุรกิจเสร็จสมบูรณ์แล้ว

การสร้างและส่งคำสั่งซื้อต้องได้รับอนุญาตจากผู้ใช้ หากการเขียนข้อมูลหมดเวลารอ ให้ตรวจสอบสถานะคำสั่งซื้อที่มีอยู่ก่อนลองใหม่ หากต้องการสิทธิ์เข้าถึงหรือพบความสามารถที่ยังใช้ไม่ได้ ให้ติดต่อผู้แทน Biointron ที่จัดเตรียมบัญชีให้คุณ

## คำถามที่พบบ่อย

<details>
<summary><strong>ฉันจำเป็นต้องใช้ทั้ง MCP และ Skills หรือไม่?</strong></summary>

MCP มีเครื่องมือให้เรียกใช้ ส่วน Skills เพิ่มคำแนะนำขั้นตอนการทำงานและอาจมีส่วนประกอบที่ต้องใช้ร่วมกันของตนเอง โปรดปฏิบัติตามข้อกำหนดของ Skill แต่ละตัวที่เผยแพร่แล้ว การดาวน์โหลด Skill เพียงอย่างเดียวไม่ได้เชื่อมต่อบริการให้

</details>

<details>
<summary><strong>การที่เครื่องมือปรากฏในรายการหมายความว่าพร้อมใช้กับงานธุรกิจแล้วหรือไม่?</strong></summary>

ไม่ใช่ การค้นพบยืนยันเพียงว่าเครื่องมือลงทะเบียนแล้ว ยังต้องตรวจสอบการตั้งค่าระบบเบื้องหลัง สิทธิ์เข้าถึงบัญชี และการดำเนินการที่ร้องขอด้วย รายการเครื่องมือระบุความแตกต่างนี้ไว้

</details>

<details>
<summary><strong>เซิร์ฟเวอร์และส่วนการทำงานทางธุรกิจอยู่ที่ไหน?</strong></summary>

คลังโค้ดนี้เผยแพร่เอกสารการเชื่อมต่อสาธารณะและ Skills ส่วนบริการที่โฮสต์ไว้และระบบการทำงานทางธุรกิจภายในได้รับการดูแลแยกต่างหาก

</details>
