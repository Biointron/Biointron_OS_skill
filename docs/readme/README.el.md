## Μία πλατφόρμα. Τρεις τρόποι σύνδεσης.

Το Biointron OS είναι μια διεπαφή προς τις υπηρεσίες Biointron για AI agents, μοντέλα και ανθρώπους. Συνδυάζει την πρόσβαση στις υπηρεσίες με οδηγίες ροής εργασίας, με ένα σχέδιο ανάπτυξης που καλύπτει παραγγελίες, υποβολή σχεδίων, πρόοδο και αποτελέσματα.

| Για agents | Για μοντέλα | Για ανθρώπους |
| :--- | :--- | :--- |
| Ανακαλύψτε και καλέστε υπηρεσίες μέσω **MCP**. | Εργαστείτε με **δομημένα δεδομένα** και τεκμηριωμένες διεπαφές. | Αποκτήστε πρόσβαση στις ροές εργασίας μέσω μιας **διαδραστικής διεπαφής**. |
| Συνδυάστε τις κλήσεις εργαλείων με Skills ειδικά για κάθε εργασία. | Οι συμβάσεις δεδομένων εναρμονίζονται κατά τη διάρκεια της Beta. | Η εμπειρία web παρέχεται χωριστά από αυτό το αποθετήριο. |

Αυτό το αποθετήριο αποτελεί το δημόσιο σημείο διάθεσης των Skills, των οδηγών σύνδεσης, του καταλόγου εργαλείων και των παραδειγμάτων. Οι επιχειρησιακές υπηρεσίες Biointron λειτουργούν χωριστά.

## Ξεκινήστε

### 1 · Συνδέστε το MCP

Λάβετε το διακριτικό πρόσβασης στην υπηρεσία και τις απαραίτητες άδειες από τον υπεύθυνο επικοινωνίας σας στη Biointron. Σε έναν πελάτη MCP που υποστηρίζει **Streamable HTTP** και **έλεγχο ταυτότητας Bearer**, προσθέστε:

| Ρύθμιση | Τιμή |
| :--- | :--- |
| Όνομα | `BiointronOS_MCP` |
| Μεταφορά | Streamable HTTP |
| URL | `https://mcp-rusta-order-blgdfvompw.cn-shanghai.fcapp.run/mcp` |
| Έλεγχος ταυτότητας | `Authorization: Bearer <MCP_ACCESS_TOKEN>` |

Σε πελάτες που υποστηρίζουν τη μορφή `mcpServers`, συγχωνεύστε αυτή τη διαμόρφωση με τις υπάρχουσες ρυθμίσεις και αντικαταστήστε την προσωρινή τιμή με το δικό σας διακριτικό:

```json
{
  "mcpServers": {
    "BiointronOS_MCP": {
      "url": "https://mcp-rusta-order-blgdfvompw.cn-shanghai.fcapp.run/mcp",
      "headers": {
        "Authorization": "Bearer <MCP_ACCESS_TOKEN>",
        "START_MCP_TIMEOUT_MS": "60000",
        "RUN_MCP_TIMEOUT_MS": "660000"
      }
    }
  }
}
```

Οι δύο κεφαλίδες χρονικού ορίου είναι προσαρμοσμένα στοιχεία της ενδεικτικής διαμόρφωσης: 60000 ms = 60 δευτερόλεπτα και 660000 ms = 11 λεπτά. Έχουν αποτέλεσμα μόνο αν τις υποστηρίζει ο πελάτης ή η υπηρεσία· η προσθήκη τους στο `headers` από μόνη της δεν εγγυάται αλλαγή του χρόνου αναμονής του πελάτη. Ρυθμίστε τα χρονικά όρια σύμφωνα με την τεκμηρίωση του πελάτη σας.

Για περισσότερες λεπτομέρειες, δείτε τον [οδηγό εγκατάστασης](../../docs/installation.md#mcp).

### 2 · Προσθέστε Skills

Επιλέξτε ένα από τα Skills που περιλαμβάνονται στον [κατάλογο Skills](../../skills/README.md). Κατεβάστε ολόκληρο τον φάκελό του, μαζί με το `references/` και τυχόν συνοδευτικά scripts, και τοποθετήστε τον στον κατάλογο Skills του agent σας. Δείτε την [εγκατάσταση Skills](../../docs/installation.md#skills) για Codex και Claude Code.

Και τα δύο πακέτα περιλαμβάνονται πλέον στο αποθετήριο: `skills/order_design/` για το `order-design` και `skills/auto_html_report/` για το `auto-html-report`. Είναι διαθέσιμα για λήψη· η παρουσία τους δεν αποδεικνύει ότι έχει επαληθευτεί ολόκληρη η επιχειρησιακή ροή.

### 3 · Δοκιμάστε μια εισαγωγή μόνο για ανάγνωση

```text
Παράθεσε τα εργαλεία MCP Biointron που είναι διαθέσιμα σε αυτή τη συνεδρία και εξήγησε τι κάνει το καθένα.
Πες μου ποιες δυνατότητες είναι έτοιμες και ποιες παραμένουν σε Beta.
Μη δημιουργήσεις και μην υποβάλεις παραγγελία.
```

Η ανακάλυψη εργαλείων είναι ο πρώτος έλεγχος σύνδεσης. Για να ολοκληρωθεί επιτυχώς μια επιχειρησιακή λειτουργία, απαιτείται η αντίστοιχη επικυρωμένη σύνδεση με το backend.

## Κατάλογος εργαλείων MCP

| Εργαλείο | Σκοπός | Επίδραση |
| :--- | :--- | :--- |
| `get_order_input_requirements` | Συλλέγει από προεπιλογή ομάδες ανεξάρτητων ερωτήσεων· ελέγχει συνολικά τα δεδομένα του σταδίου πριν από την εγγραφή. Δεν απαιτεί επιχειρησιακό JWT. | Μόνο ανάγνωση |
| `search_order_antigens` | Αναζητά πραγματικά προϊόντα και προδιαγραφές με λέξη-κλειδί και επιστρέφει πληροφορίες για τη συνέχεια των σελίδων. | Μόνο ανάγνωση |
| `order_design_preflight` | Ελέγχει την επιλεξιμότητα της εταιρείας και τις διαθέσιμες εξετάσεις. | Μόνο ανάγνωση |
| `start_order_design` | Υποβάλλει το παρεχόμενο XLSX και περιμένει επιβεβαίωση αποθήκευσης του σχεδιασμού. | Εγγράφει επιχειρησιακά δεδομένα |
| `get_order_design_result` | Μετά την επιλογή του πελάτη, διαβάζει το πραγματικό HTML του αποθηκευμένου σχεδιασμού για παράδοση, χωρίς αλλαγή της παραγγελίας. | Μόνο ανάγνωση |
| `add_order_to_cart` | Προσθέτει τον επιβεβαιωμένα αποθηκευμένο σχεδιασμό στο καλάθι. | Εγγράφει επιχειρησιακά δεδομένα |
| `end_order_workflow` | Οδηγία στον πελάτη να απορρίψει το τοπικό πλαίσιο, χωρίς ανάκληση υπογραφής ή ακύρωση παραγγελίας. | Μόνο οδηγία πελάτη |
| `get_order_cart` | Διαβάζει το καλάθι παραγγελιών. | Μόνο ανάγνωση |
| `calculate_order_price` | Λαμβάνει προσφορά για τις επιλεγμένες παραγγελίες. | Μόνο ανάγνωση |
| `submit_verified_order` | Ελέγχει την προσφορά και υποβάλλει τις επιλεγμένες παραγγελίες για επιβεβαίωση από προσωπικό. | Εγγράφει επιχειρησιακά δεδομένα |
| `get_report_results` | Ανακτά αποτελέσματα υπαρχουσών αναφορών σε JSON. | Μόνο ανάγνωση |

Η τοπική υλοποίηση περιλαμβάνει **11 εργαλεία**: 10 απαιτούν το JWT του τρέχοντος πελάτη στο `business_token`· το `get_order_input_requirements` λειτουργεί τοπικά χωρίς JWT. Αυτή η ενημέρωση δεν έχει ακόμη αναπτυχθεί στην υπηρεσία και η πλήρης επιχειρησιακή ροή παραμένει ανεπιβεβαίωτη σε πραγματικό περιβάλλον. Δείτε [υπογραφές, κατάσταση και περιορισμούς](../../docs/tool-catalog.md).

## Skills

| Skill | Σκοπός | Κατάσταση έκδοσης |
| :--- | :--- | :--- |
| [Σχεδιασμός παραγγελιών · `order-design`](../../skills/order_design/SKILL.md) | Εξηγεί τα πακέτα, συλλέγει στοιχεία σε ομάδες, καθοδηγεί την επιλογή προϊόντων καταλόγου, προσφέρει προαιρετική προβολή HTML μετά την αποθήκευση του σχεδιασμού, ελέγχει καλάθι και προσφορές και υποβάλλει παραγγελίες για επιβεβαίωση από προσωπικό. | Περιλαμβάνεται· διαθέσιμο για λήψη |
| [Αναφορά αποτελεσμάτων · `auto-html-report`](../../skills/auto_html_report/SKILL.md) | Δημιουργεί αυτοτελείς αναφορές HTML σε πολλές γλώσσες από αποτελέσματα JSON που παρέχει ο χρήστης, με συνοπτικούς πίνακες, γραφήματα και διαθέσιμες εικόνες. | Περιλαμβάνεται· διαθέσιμο για λήψη |

Το MCP εκθέτει λειτουργίες· τα Skills περιγράφουν πώς τις χρησιμοποιεί ένας agent στο πλαίσιο μιας εργασίας. Η εγκατάσταση ενός Skill δεν παραχωρεί πρόσβαση στην υπηρεσία ούτε καταχωρίζει αυτόματα το MCP. [Περιηγηθείτε στον κατάλογο →](../../skills/README.md)

Η υποβληθείσα παραγγελία αναμένει επιβεβαίωση από τη Biointron· η υποβολή δεν αποδεικνύει έναρξη παραγωγής ή ολοκλήρωση πειραμάτων.

Όταν έχουν ήδη δοθεί αποτελέσματα JSON, το Skill `auto-html-report` δημιουργεί την αναφορά τοπικά, χωρίς διαπιστευτήρια ή σύνδεση MCP. Αν λείπει το JSON, μια εξουσιοδοτημένη αναζήτηση μπορεί να χρησιμοποιήσει τον αριθμό παραγγελίας και το JWT του τρέχοντος πελάτη μέσω του `get_report_results`, ώστε να ανακτήσει αποτελέσματα πριν δημιουργήσει την αναφορά. Ο αριθμός παραγγελίας μόνος του δεν αρκεί. Επαναχρησιμοποιήστε ένα έγκυρο JWT· μόνο όταν χρειάζεται να αποκτηθεί JWT, χρησιμοποιήστε τα διαθέσιμα Biointron Account και App Key και ζητήστε μόνο όσα στοιχεία λείπουν.

Οι οδηγίες του πακέτου αναφορών είναι στα αγγλικά, αλλά η αναφορά ακολουθεί τη γλώσσα που ζητά ο πελάτης.

## Beta Playground

Το Biointron OS παρουσιάζεται ως Beta Playground. Ορισμένες συνδέσεις ενδέχεται να μην είναι ακόμη διαθέσιμες. Αναφέρετε το πραγματικό αποτέλεσμα κάθε βήματος· μια επιτυχής απόκριση HTTP ή η εμφάνιση του ονόματος ενός εργαλείου δεν αποδεικνύει ότι ολοκληρώθηκε μια επιχειρησιακή λειτουργία.

Η δημιουργία και η υποβολή παραγγελιών απαιτούν εξουσιοδότηση από τον χρήστη. Αν μια εγγραφή λήξει λόγω χρονικού ορίου, ελέγξτε την κατάσταση της υπάρχουσας παραγγελίας πριν δοκιμάσετε ξανά. Για πρόσβαση ή για μια μη διαθέσιμη δυνατότητα, επικοινωνήστε με τον εκπρόσωπο της Biointron που σας παρείχε τον λογαριασμό.

## Συχνές ερωτήσεις

<details>
<summary><strong>Χρειάζομαι και MCP και Skills;</strong></summary>

Το MCP παρέχει εργαλεία που μπορούν να κληθούν. Τα Skills προσθέτουν οδηγίες ροής εργασίας και μπορεί να έχουν δικές τους εξαρτήσεις. Ακολουθήστε τις απαιτήσεις κάθε δημοσιευμένου Skill· η λήψη ενός Skill από μόνη της δεν συνδέει μια υπηρεσία.

</details>

<details>
<summary><strong>Η εμφάνιση ενός εργαλείου στη λίστα σημαίνει ότι είναι έτοιμο για επιχειρησιακή χρήση;</strong></summary>

Όχι. Η ανακάλυψη επιβεβαιώνει ότι το εργαλείο έχει καταχωριστεί. Πρέπει επίσης να επικυρωθούν η διαμόρφωση του backend, η πρόσβαση του λογαριασμού και η ζητούμενη λειτουργία. Ο κατάλογος καταγράφει αυτή τη διάκριση.

</details>

<details>
<summary><strong>Πού βρίσκονται ο διακομιστής και η επιχειρησιακή υλοποίηση;</strong></summary>

Αυτό το αποθετήριο διανέμει δημόσιο υλικό ενσωμάτωσης και Skills. Η φιλοξενούμενη υπηρεσία και η ιδιωτική επιχειρησιακή υλοποίηση συντηρούνται χωριστά.

</details>
