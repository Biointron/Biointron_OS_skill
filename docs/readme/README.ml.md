## ഒരു പ്ലാറ്റ്‌ഫോം. ബന്ധിപ്പിക്കാൻ മൂന്ന് വഴികൾ.

AI ഏജന്റുകൾക്കും മോഡലുകൾക്കും ആളുകൾക്കും Biointron സേവനങ്ങൾ ലഭ്യമാക്കുന്ന ഇന്റർഫേസാണ് Biointron OS. സേവനങ്ങളിലേക്കുള്ള പ്രവേശനവും പ്രവർത്തനക്രമത്തിനുള്ള മാർഗനിർദേശവും ഇത് ഒരുമിപ്പിക്കുന്നു. ഓർഡറുകൾ, ഡിസൈൻ സമർപ്പണം, പുരോഗതി, ഫലങ്ങൾ എന്നിവ ഉൾക്കൊള്ളുന്നതാണ് ഇതിന്റെ വികസനപദ്ധതി.

| ഏജന്റുകൾക്കായി | മോഡലുകൾക്കായി | ആളുകൾക്കായി |
| :--- | :--- | :--- |
| **MCP** വഴി സേവനങ്ങൾ കണ്ടെത്തുകയും വിളിക്കുകയും ചെയ്യുക. | **ഘടനാബദ്ധമായ ഡാറ്റയും** രേഖപ്പെടുത്തിയ ഇന്റർഫേസുകളും ഉപയോഗിച്ച് പ്രവർത്തിക്കുക. | **സംവേദനാത്മക ഇന്റർഫേസ്** വഴി പ്രവർത്തനക്രമങ്ങൾ ഉപയോഗിക്കുക. |
| ടൂൾ കോളുകൾക്കൊപ്പം ഓരോ ജോലിക്കും അനുയോജ്യമായ Skills ഉപയോഗിക്കുക. | Beta ഘട്ടത്തിൽ ഡാറ്റാ മാനദണ്ഡങ്ങൾ ഏകീകരിച്ചുകൊണ്ടിരിക്കുന്നു. | വെബ് അനുഭവം ഈ റിപ്പോസിറ്ററിയിൽനിന്ന് വേറിട്ട് ലഭ്യമാക്കുന്നു. |

Skills, കണക്ഷൻ മാർഗനിർദേശങ്ങൾ, ടൂൾ പട്ടിക, ഉദാഹരണങ്ങൾ എന്നിവയുടെ പൊതുവിതരണ കേന്ദ്രമാണ് ഈ റിപ്പോസിറ്ററി. Biointron-ന്റെ ബിസിനസ് സേവനങ്ങൾ വേറിട്ടാണ് പ്രവർത്തിക്കുന്നത്.

## തുടങ്ങുക

### 1 · MCP ബന്ധിപ്പിക്കുക

നിങ്ങളുടെ Biointron പ്രതിനിധിയിൽനിന്ന് സേവനത്തിലേക്കുള്ള ആക്‌സസ് ടോക്കണും ആവശ്യമായ അനുമതികളും നേടുക. **Streamable HTTP**, **Bearer authentication** എന്നിവ പിന്തുണയ്ക്കുന്ന MCP ക്ലയന്റിൽ താഴെപ്പറയുന്നവ ചേർക്കുക:

| ക്രമീകരണം | മൂല്യം |
| :--- | :--- |
| പേര് | `BiointronOS_MCP` |
| ട്രാൻസ്പോർട്ട് | Streamable HTTP |
| URL | `https://mcp-rusta-order-blgdfvompw.cn-shanghai.fcapp.run/mcp` |
| പ്രാമാണീകരണം | `Authorization: Bearer <MCP_ACCESS_TOKEN>` |

`mcpServers` ഫോർമാറ്റ് പിന്തുണയ്ക്കുന്ന ക്ലയന്റുകളിൽ, ഈ ക്രമീകരണം നിലവിലുള്ള ക്രമീകരണങ്ങളുമായി ലയിപ്പിച്ച് പ്ലേസ്‌ഹോൾഡറിന് പകരം നിങ്ങളുടെ സ്വന്തം ടോക്കൺ നൽകുക:

```json
{
  "mcpServers": {
    "BiointronOS_MCP": {
      "url": "https://mcp-rusta-order-blgdfvompw.cn-shanghai.fcapp.run/mcp",
      "headers": {
        "Authorization": "Bearer <MCP_ACCESS_TOKEN>",
        "START_MCP_TIMEOUT_MS": "60000",
        "RUN_MCP_TIMEOUT_MS": "660000"
      }
    }
  }
}
```

രണ്ട് ടൈംഔട്ട് ഹെഡറുകളും ഈ മാതൃകാ ക്രമീകരണത്തിലെ കസ്റ്റം ഇനങ്ങളാണ്: 60000 മില്ലിസെക്കൻഡ് = 60 സെക്കൻഡ്; 660000 മില്ലിസെക്കൻഡ് = 11 മിനിറ്റ്. ക്ലയന്റോ സേവനമോ ഈ ഹെഡറുകൾ പിന്തുണച്ചാൽ മാത്രമേ അവയ്ക്ക് ഫലമുണ്ടാകൂ; അവ `headers`-ൽ ചേർക്കുന്നതുകൊണ്ട് മാത്രം ക്ലയന്റിന്റെ കാത്തിരിപ്പ് സമയം മാറുമെന്ന് ഉറപ്പില്ല. ഉപയോഗിക്കുന്ന ക്ലയന്റിന്റെ രേഖകൾ അനുസരിച്ച് ടൈംഔട്ട് ക്രമീകരിക്കുക.

കൂടുതൽ വിവരങ്ങൾക്ക് [ഇൻസ്റ്റലേഷൻ മാർഗനിർദേശം](../../docs/installation.md#mcp) കാണുക.

### 2 · Skills ചേർക്കുക

[Skills പട്ടികയിൽ](../../skills/README.md) ഉൾപ്പെടുത്തിയിട്ടുള്ള ഒരു Skill തിരഞ്ഞെടുക്കുക. `references/` ഡയറക്ടറിയും നൽകിയിട്ടുള്ള സ്ക്രിപ്റ്റുകളും ഉൾപ്പെടെ മുഴുവൻ ഫോൾഡറും ഡൗൺലോഡ് ചെയ്ത് നിങ്ങളുടെ ഏജന്റിന്റെ Skill ഡയറക്ടറിയിൽ വയ്ക്കുക. Codex, Claude Code എന്നിവയ്ക്കായി [Skill ഇൻസ്റ്റലേഷൻ](../../docs/installation.md#skills) കാണുക.

രണ്ട് പാക്കേജുകളും ഇപ്പോൾ ഈ റിപ്പോസിറ്ററിയിൽ ഉൾപ്പെടുത്തിയിട്ടുണ്ട്: `order-design` എന്നതിന് `skills/order_design/`, `auto-html-report` എന്നതിന് `skills/auto_html_report/`. അവ ഡൗൺലോഡ് ചെയ്യാം; പാക്കേജുകൾ ഉൾപ്പെടുത്തിയതുകൊണ്ട് മുഴുവൻ ബിസിനസ് പ്രവർത്തനക്രമവും പരിശോധിച്ച് ഉറപ്പാക്കിയതായി അർഥമില്ല.

### 3 · വായനയ്ക്ക് മാത്രമുള്ള ഒരു പരിചയപ്പെടൽ പരീക്ഷിക്കുക

```text
ഈ സെഷനിൽ ലഭ്യമായ Biointron MCP ടൂളുകൾ പട്ടികപ്പെടുത്തുകയും ഓരോന്നിന്റെയും പ്രവർത്തനം വിശദീകരിക്കുകയും ചെയ്യുക.
ഏതെല്ലാം കഴിവുകൾ തയ്യാറായെന്നും ഏതെല്ലാം ഇപ്പോഴും Beta ഘട്ടത്തിലാണെന്നും പറയുക.
ഓർഡർ സൃഷ്ടിക്കുകയോ സമർപ്പിക്കുകയോ ചെയ്യരുത്.
```

ടൂളുകൾ കണ്ടെത്തുന്നതാണ് കണക്ഷന്റെ ആദ്യ പരിശോധന. ഒരു ബിസിനസ് പ്രവർത്തനം വിജയിക്കാൻ അതുമായി ബന്ധപ്പെട്ട ബാക്കെൻഡ് കണക്ഷൻ പ്രത്യേകം സാധൂകരിക്കേണ്ടതുണ്ട്.

| `calculate_order_price` | തിരഞ്ഞെടുത്ത ഓർഡറുകളുടെ നിരക്ക് ലഭ്യമാക്കുന്നു. | വായനയ്ക്ക് മാത്രം |
| `submit_verified_order` | വിലക്കണക്ക് പരിശോധിച്ച് തിരഞ്ഞെടുത്ത ഓർഡറുകൾ ജീവനക്കാരുടെ സ്ഥിരീകരണത്തിനായി സമർപ്പിക്കുന്നു. | ബിസിനസ് ഡാറ്റ എഴുതുന്നു |
| `get_report_results` | നിലവിലുള്ള റിപ്പോർട്ടുകളുടെ ഫലങ്ങൾ JSON ആയി ലഭ്യമാക്കുന്നു. | വായനയ്ക്ക് മാത്രം |

പ്രാദേശിക നടപ്പാക്കലിൽ **11 ടൂളുകൾ** ഉണ്ട്: 10 ടൂളുകൾക്ക് നിലവിലെ ഉപഭോക്താവിന്റെ JWT `business_token` ആയി വേണം; `get_order_input_requirements` JWT ഇല്ലാതെ പ്രാദേശികമായി പ്രവർത്തിക്കുന്നു. ഈ പുതുക്കൽ സേവനത്തിൽ ഇതുവരെ വിന്യസിച്ചിട്ടില്ല; തുടക്കം മുതൽ അവസാനം വരെയുള്ള ബിസിനസ് പ്രവർത്തനം യഥാർത്ഥ പരിതസ്ഥിതിയിൽ സ്ഥിരീകരിക്കാനുണ്ട്. [ടൂൾ സിഗ്നേച്ചറുകൾ, നില, പരിമിതികൾ](../../docs/tool-catalog.md) കാണുക.

## Skills

| :--- | :--- | :--- |
| [ഓർഡർ ഡിസൈൻ · `order-design`](../../skills/order_design/SKILL.md) | പാക്കേജുകൾ വിശദീകരിക്കുന്നു, വിവരങ്ങൾ കൂട്ടങ്ങളായി ശേഖരിക്കുന്നു, കാറ്റലോഗിൽനിന്ന് ഉൽപ്പന്നങ്ങൾ തിരഞ്ഞെടുക്കാൻ സഹായിക്കുന്നു, ഡിസൈൻ സംരക്ഷിച്ചശേഷം ആവശ്യമെങ്കിൽ HTML കാണിക്കുന്നു, കാർട്ടും വിലക്കണക്കും പരിശോധിച്ച് ഓർഡറുകൾ ജീവനക്കാരുടെ സ്ഥിരീകരണത്തിനായി സമർപ്പിക്കുന്നു. | ഉൾപ്പെടുത്തിയിട്ടുണ്ട്; ഡൗൺലോഡ് ചെയ്യാം |
| [ഫലങ്ങളുടെ റിപ്പോർട്ട് · `auto-html-report`](../../skills/auto_html_report/SKILL.md) | ഉപയോക്താവ് നൽകിയ നിലവിലുള്ള ഫലങ്ങളുടെ JSON ഉപയോഗിച്ച് സംഗ്രഹ പട്ടികകളും ചാർട്ടുകളും ലഭ്യമായ ചിത്രങ്ങളും ഉൾപ്പെടുന്ന സ്വതന്ത്ര HTML റിപ്പോർട്ടുകൾ വിവിധ ഭാഷകളിൽ സൃഷ്ടിക്കുന്നു. | ഉൾപ്പെടുത്തിയിട്ടുണ്ട്; ഡൗൺലോഡ് ചെയ്യാം |

MCP പ്രവർത്തനങ്ങൾ ലഭ്യമാക്കുന്നു; ഒരു ജോലിക്കിടെ ഏജന്റ് അവ എങ്ങനെ ഉപയോഗിക്കണമെന്ന് Skills വിശദീകരിക്കുന്നു. Skill ഇൻസ്റ്റാൾ ചെയ്യുന്നത് സേവനപ്രവേശനം അനുവദിക്കുകയോ MCP സ്വയം രജിസ്റ്റർ ചെയ്യുകയോ ചെയ്യുന്നില്ല. [പട്ടിക കാണുക →](../../skills/README.md)

സമർപ്പിച്ച ഓർഡർ Biointron-ന്റെ സ്ഥിരീകരണത്തിനായി കാത്തിരിക്കുന്നു; സമർപ്പണം ഉൽപ്പാദനം തുടങ്ങിയതിന്റെയോ പരീക്ഷണം പൂർത്തിയായതിന്റെയോ തെളിവല്ല.

ഫലങ്ങളുടെ JSON നേരത്തെ നൽകിയിട്ടുണ്ടെങ്കിൽ, `auto-html-report` Skill പ്രവേശനവിവരങ്ങളോ MCP കണക്ഷനോ ഇല്ലാതെ റിപ്പോർട്ട് പ്രാദേശികമായി സൃഷ്ടിക്കുന്നു. JSON ഇല്ലെങ്കിൽ, അനുമതിയുള്ള അന്വേഷണത്തിന് ഓർഡർ നമ്പറും നിലവിലെ ഉപഭോക്താവിന്റെ JWT-യും ഉപയോഗിച്ച് `get_report_results` വഴി ഫലങ്ങൾ ആദ്യം ലഭ്യമാക്കി തുടർന്ന് റിപ്പോർട്ട് സൃഷ്ടിക്കാം. ഓർഡർ നമ്പർ മാത്രം മതിയാകില്ല. സാധുവായ JWT വീണ്ടും ഉപയോഗിക്കുക; JWT ലഭ്യമാക്കേണ്ടപ്പോൾ മാത്രം നിലവിലുള്ള Biointron Account, App Key എന്നിവ പുനരുപയോഗിച്ച് ഇല്ലാത്ത വിവരങ്ങൾ മാത്രം ചോദിക്കുക.

റിപ്പോർട്ട് പാക്കേജിലെ നിർദേശങ്ങൾ ഇംഗ്ലീഷിലാണ്; ഉപഭോക്താവ് ആവശ്യപ്പെടുന്ന ഭാഷയിലാണ് റിപ്പോർട്ട് തയ്യാറാക്കുന്നത്.

## Beta Playground

Beta Playground എന്ന നിലയിലാണ് Biointron OS അവതരിപ്പിക്കുന്നത്. ചില കണക്ഷനുകൾ ഇപ്പോഴും ലഭ്യമല്ലായിരിക്കാം. ഓരോ ഘട്ടത്തിന്റെയും യഥാർഥ ഫലം അറിയിക്കുക; വിജയകരമായ HTTP പ്രതികരണമോ ദൃശ്യമാകുന്ന ടൂളിന്റെ പേരോ ഒരു ബിസിനസ് പ്രവർത്തനം പൂർത്തിയായി എന്നതിന് തെളിവല്ല.

ഓർഡറുകൾ സൃഷ്ടിക്കാനും സമർപ്പിക്കാനും ഉപയോക്താവിന്റെ അനുമതി ആവശ്യമാണ്. ഡാറ്റ എഴുതുന്ന പ്രവർത്തനത്തിന്റെ സമയപരിധി കഴിഞ്ഞാൽ, വീണ്ടും ശ്രമിക്കുന്നതിനുമുമ്പ് നിലവിലുള്ള ഓർഡറിന്റെ നില പരിശോധിക്കുക. പ്രവേശനത്തിനോ ലഭ്യമല്ലാത്ത കഴിവുകളെക്കുറിച്ചുള്ള വിവരങ്ങൾക്കോ നിങ്ങളുടെ അക്കൗണ്ട് നൽകിയ Biointron പ്രതിനിധിയെ ബന്ധപ്പെടുക.

## പതിവുചോദ്യങ്ങൾ

<details>
<summary><strong>MCP-യും Skills-ഉം രണ്ടും ആവശ്യമാണോ?</strong></summary>

വിളിച്ച് ഉപയോഗിക്കാവുന്ന ടൂളുകളാണ് MCP നൽകുന്നത്. Skills പ്രവർത്തനക്രമത്തിനുള്ള നിർദേശങ്ങൾ ചേർക്കുന്നു; അവയ്ക്ക് സ്വന്തമായ ആശ്രിത ഘടകങ്ങളും ഉണ്ടായേക്കാം. പ്രസിദ്ധീകരിച്ച ഓരോ Skill-ന്റെയും ആവശ്യകതകൾ പാലിക്കുക; Skill ഡൗൺലോഡ് ചെയ്യുന്നതുകൊണ്ട് മാത്രം സേവനവുമായി കണക്ഷൻ ഉണ്ടാകില്ല.

</details>

<details>
<summary><strong>ഒരു ടൂൾ പട്ടികയിൽ കാണുന്നത് അത് ബിസിനസ് ഉപയോഗത്തിന് തയ്യാറാണെന്ന് അർഥമാക്കുമോ?</strong></summary>

ഇല്ല. ടൂൾ കണ്ടെത്താനാകുന്നത് അത് രജിസ്റ്റർ ചെയ്തിട്ടുണ്ടെന്ന് മാത്രമാണ് സ്ഥിരീകരിക്കുന്നത്. ബാക്കെൻഡ് ക്രമീകരണം, അക്കൗണ്ടിന്റെ പ്രവേശനാവകാശം, ആവശ്യപ്പെട്ട പ്രവർത്തനം എന്നിവയും സാധൂകരിക്കണം. പട്ടികയിൽ ഈ വ്യത്യാസം വ്യക്തമാക്കിയിട്ടുണ്ട്.

</details>

<summary><strong>സെർവറും ബിസിനസ് നടപ്പാക്കലും എവിടെയാണ്?</strong></summary>

പൊതുവായ ഇന്റഗ്രേഷൻ വിവരങ്ങളും Skills-ഉം ഈ റിപ്പോസിറ്ററി വിതരണം ചെയ്യുന്നു. ഹോസ്റ്റ് ചെയ്ത സേവനവും സ്വകാര്യ ബിസിനസ് നടപ്പാക്കലും വേറിട്ട് പരിപാലിക്കുന്നു.

</details>
